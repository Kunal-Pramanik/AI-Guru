# AI Guru 🦉

AI Guru turns textbook pages into stories, games, notes and quizzes for Classes 1–5. Everything works in **English, हिंदी and ગુજરાતી**, including the whole interface, and Guru can read everything aloud.

## Run it on your laptop (Windows)

1. Unzip this folder, for example to `D:\Projects Random\ai-guru-v2`.
2. Copy `.env.example` to `.env.local`, and put your key after `GEMINI_API_KEY=`. (Or copy your old `.env.local` in.)
3. In a terminal inside the folder, run:
   ```
   npm install
   npm run check-ai
   npm run dev
   ```
   `check-ai` confirms your key works and shows which Gemini models it can use.
4. Open http://localhost:3000 in **Chrome**.
5. **Tonight:** open the sample chapter once and upload your real chapter once, using the same class, language and learning style you'll use tomorrow. The lesson, translations and every illustration get saved to `.ai-guru-cache/`. Tomorrow the same upload loads instantly and uses no API quota.

Checks: `npm run typecheck`, `npm run lint`, `npm run build`.

## What's inside

| Part | What it does |
|---|---|
| `app/page.tsx` | Onboarding in 4 steps (language → name + buddy → class + learning style → upload). PDF/photo upload, live camera capture, previews with remove, 8 files / 15 MB limits, built-in sample chapter |
| `app/api/prepare-lessons/route.ts` | Sends the pages to Gemini (`gemini-2.5-flash`) and gets back structured JSON based only on the textbook: subtopics, stories, explanations, key points, notes, key words, quiz, match pairs and challenges. All of this comes from **one** API call |
| `app/api/translate-lessons/route.ts` | Translates the full chapter. The correct quiz answer is kept by **index**, so a translation can't change which option is right. Results are cached on the server and in sessionStorage |
| `lib/gemini.ts` | Model fallback chain. Retries 429/503/timeouts with exponential backoff (4 tries max, the last one on a "lite" model), shows friendly errors and never exposes the key. Large uploads go through the Files API |
| `lib/illustrator.ts` | AI illustration pipeline (SVG drawing on the free tier, image model when billed) with a disk cache and SVG cleanup |
| `lib/lesson.ts` | Validates and cleans up every model response: 4 options per question, re-aligned answers, no duplicate or ambiguous match pairs, 3 distinct challenges, with fallbacks built from the lesson's own data |
| `app/learn/page.tsx` + `components/stages/*` | Dashboard and the 5 stages |
| `lib/useSpeech.ts` | Web Speech API narration (en-IN / hi-IN / gu-IN) that reads sentence by sentence, never overlaps, stops when a stage closes, and tells the child if a voice is missing |
| `lib/progress.ts` | Progress, stars and badges saved in localStorage, so they survive a refresh |
| `lib/demoLesson.ts` | Hand-written sample chapter in 3 languages that works offline with no API |
| `lib/i18n.ts` | All interface text in English, Hindi and Gujarati |

### The 5 stages
1. **Watch & Discover**: a storybook player. The picture moves slowly, the story appears sentence by sentence like subtitles, and Guru narrates. There is one story per subtopic plus a whole-chapter story whose pictures change part by part. If no voice is installed, it plays as an automatic slideshow.
2. **Explore & Play**: *Discover & Learn* (each part with its explanation, key points and "what the book says"), *Match & Learn* (tap a card on the left, then its partner on the right; stars, celebration, replay), and *Quick Challenge* (3 distinct challenges using flip flashcards and true/false, with score and replay).
3. **Smart Notes**: colour-coded notes with **highlighted key words**, key-word cards, and "read all" with the current line highlighted.
4. **Quiz Time**: one question at a time with instant feedback, the correct answer highlighted, an explanation, numbered question dots for moving around, a final score, retry, and the stage marked done automatically.
5. **My Achievements**: total stars, progress ring, best quiz score, stage checklist and 6 badges.

### AI-generated illustrations (no hand-made images)
Every picture is generated by the app itself (`lib/illustrator.ts`, `app/api/illustrate`):
1. The lesson step writes a `visualDescription` for each subtopic, based on the textbook.
2. After the dashboard opens, the app asks for one illustration per subtopic, one at a time. While a picture is being made, the child sees animated scene art and a "Guru is drawing…" badge.
3. **Free key:** Gemini *draws* the scene as SVG vector art (3D-style gradients and shadows). The SVG is cleaned up before use (scripts, links and external images are removed) and shown through `<img>`, so it can never run code.
4. **Billed key:** the Gemini image model makes a raster 3D storybook picture. `IMAGE_MODE=auto` (the default) tries this first and switches to SVG on a quota or billing error.
5. Every picture is saved on disk (`.ai-guru-cache/`), so each one is generated only once.

### Staying inside the free daily quota
Free-tier daily limits reset at **midnight Pacific time (1:30 PM IST)**, so the night before a 12 PM demo and the demo itself share one quota day.
- **Lessons are saved by file content.** Uploading the same pages with the same class, language and learning style again loads the saved lesson with **0 API requests**. Its pictures are already saved too.
- **Translations are saved on disk**, so switching language costs a request only the first time.
- **Pictures are drawn by the Flash-Lite model**, which has a much larger free daily quota, so they don't use up the Flash requests needed for lessons.
- **When a model's daily quota runs out, the app switches straight to the Lite model** instead of retrying.
- **Backup:** rate limits are per Google Cloud *project*. A key from a second project has its own quota, so keep one ready.
- **To reset everything,** delete the `.ai-guru-cache` folder.

### Model fallback
Google retires model IDs often. `lib/gemini.ts` tries a chain of models, newest first (`gemini-3.5-flash` → `3.6` → `3.8` → `gemini-flash-latest` → `2.5-flash`). If a model is missing for your key, it moves to the next one and remembers the first that works. To force a specific model, set `GEMINI_MODEL=` in `.env.local`.

## Presentation demo script (about 5 minutes)
1. Choose **ગુજરાતી** or **हिंदी** on the first screen. The whole app switches language.
2. Enter a name, pick a buddy, class 1, Stories, then **Let's go**.
3. Upload `aemr104.pdf` (or a phone photo of a page) and press **Make my lessons**. Point out the "Guru is drawing…" badges as the pictures appear. *Backup:* if the internet or API fails, press **Try sample chapter**.
4. Open Watch & Discover → the whole-chapter story → Play.
5. Explore & Play → Match & Learn → Quick Challenge.
6. Quiz Time: answer one question wrong on purpose to show the kind feedback.
7. My Achievements, then switch the language at the top to show live translation.
8. Refresh the page to show that progress is kept.

## Honest limitations (for the paper)
- No automatic video generation yet. The storybook player is a narrated slideshow, not a generated video.
- On the free tier, illustrations are AI-drawn vector art (SVG), which is simpler than raster 3D renders. Raster images need a billed key.
- Free-tier rate limits mean a chapter's pictures can take 1–3 minutes to finish (they appear one by one).
- Read-aloud depends on the device's voices. Gujarati voices are often missing on desktop Chrome and are more common on Android.
- Progress is saved per device in the browser (no database or accounts).
- Lesson quality depends on Gemini and on how clear the pages are. Results still need evaluation with real students.
